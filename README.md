# Tapadinho — Nature and Pool

Bilingual (PT/EN) single-page marketing site for **Casa do Tapadinho**, a
countryside Airbnb/Booking.com property in Castelo de Paiva, Portugal.
Deployed to GitHub Pages at [demo.walshe.io](https://demo.walshe.io).

See [PLAN.md](PLAN.md) for the feature roadmap and project status.

## Stack

- [Vite](https://vite.dev) (rolldown-vite) + React 19 + TypeScript
- Tailwind CSS 4
- [react-i18next](https://react.i18next.com) for PT/EN translations
- pnpm (v10+; settings live in `pnpm-workspace.yaml`)

## Development

```bash
pnpm install
make dev        # start dev server
make build      # typecheck + production build to dist/
make preview    # preview the production build
make lint       # eslint
make format     # prettier over src/
```

## Media pipeline

Source photos/video live in `temporary_media/` (gitignored). Run
`make optimize` to regenerate the optimized assets in `public/`:

- video → `public/video/hero.{webm,mp4}` + poster (requires `ffmpeg`)
- images → WebP at original size plus 640/1024/1920px variants
  (requires `sharp`, installed as a dev dependency)

Components reference the base WebP and use the width variants via
`srcSet` (see `src/utils/images.ts`).

## Structure

- `src/components/` — one component per page section (Header, Hero, About,
  Gallery, Reviews, FAQ, Location, Calendar, Footer)
- `src/locales/{en,pt}.json` — all user-facing copy; every new string needs
  a key in both files
- `src/data/reviews.json` — real guest reviews with translations
  (generated by `scripts/translate_reviews.py`, gitignored, using DeepL)
- `src/data/bookings.ts` — placeholder booking data until iCal integration

## Deployment

Pushes to `main` build and deploy to GitHub Pages via
`.github/workflows/deploy.yml`. The custom domain is configured in the
repository's Pages settings.
